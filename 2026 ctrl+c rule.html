📋 전체 대기 순서 목록 (관리자 뷰)

1번 게임 — 전선 연결

GAME 1

게임 규칙: 전선을 정확하게 연결하여 발광다이오드(LED)에 불빛이 켜지면 성공입니다.

회로를 올바르게 완성해 LED를 점등시켜 보세요!

2번 게임 — 폭탄 넘기기

GAME 2

게임 규칙: 마이크로비트(micro:bit)로 만든 폭탄 넘겨주기 게임에서, 폭탄이 상대방 손에서 터지면 성공입니다.

폭탄을 넘기다가 상대방에게 폭탄이 터지도록 해보세요!

3번 게임 — 확률 게임

GAME 3

게임 규칙: 확률 게임으로, 칸이 세 개 있습니다. 세 칸 모두에 같은 그림이 나오면 성공입니다.

운이 좀 필요한 게임입니다. 세 칸이 모두 일치할 때까지 도전!

4번 게임 — AI vs 사람 그림

GAME 4

게임 규칙: AI 그림과 사람 그림을 비교하여, 사람이 그린 그림을 맞추면 성공입니다.

눈을 믿을 수 있을까요? 진짜 사람 그림을 찾아보세요!

5번 게임 — 방탈출(예정)

🎲 5번 게임 — 준비 중입니다 방탈출 게임으로 진행 예정이며, 세부 규칙은 확정되는 대로 업데이트될 예정입니다.
